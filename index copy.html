Quick User Guide

Generate a Single SIN

  1. Select a desired first digit from 0-9 or choose Random.
  2. When Random is selected, the tool uses 1, 2, 3, 4, 5, 6, 7, or 9.
  3. Click Generate SIN.
  4. Use Copy to copy the generated SIN.

0 is excluded from random generation because a SIN cannot start with 0. 8 is excluded because it has historically been associated with business or corporate numbering structures.

Generate Multiple SINs

  1. Enter the number of SINs to generate, from 1 to 100.
  2. Select a starting digit or Random.
  3. Click Generate SINs.
  4. Use Copy beside an individual SIN or Copy all SINs.

Validate a SIN

  1. Enter or paste a 9-digit SIN.
  2. Click Validate SIN Number.
  3. The tool indicates whether the SIN passes validation.
