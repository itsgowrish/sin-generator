User Guide

1. Choose Fields

  1. Use Select All Fields, or choose individual fields.
  2. Full Name reveals optional First, Middle, and Last Name fields.
  3. Address reveals Province, City, and Include Unit Number.

2. Generate Data

  1. Set the Male/Female ratio for generated names.
  2. Choose a profile count from 1 to 100.
  3. Click Generate Test Data. Results are unique within the batch.

3. Copy or Download

  • Click any result field to copy just that value.
  • Use Copy to copy one complete profile.
  • For multiple profiles, use Copy All Profiles or Download CSV.
  • Use Clear Search Results before starting over.
